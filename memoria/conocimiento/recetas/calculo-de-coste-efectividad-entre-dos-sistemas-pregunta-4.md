Coste-efectividad = rendimiento / coste. Rendimiento = 1 / tiempo total. S1: tiempo total=25s → rendimiento=1/25 → CE=1/(25*10000)=4e-6. S2: tiempo total=50s → rendimiento=1/50 → CE=1/(50*20000)=1e-6. Ratio CE_S1/CE_S2 = 4. S1 es 4 veces más coste-efectivo (300% más), no 20%. Respuesta correcta: d) None of the above.
