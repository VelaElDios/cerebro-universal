Cost-effectiveness = rendimiento / coste. Rendimiento = 1 / tiempo de ejecución (para una carga de trabajo). Si la carga es una mezcla de programas, se suele usar la media armónica de los rendimientos (o tiempo total ponderado). Para cada sistema, calcular el tiempo total para la carga (suma de tiempos si se ejecutan secuencialmente) y luego performance = 1 / tiempo_total. Cost-effectiveness = performance / coste. Comparar ambos.
