## Resumen
Script de Python para la práctica de Arquitectura de Computadores que genera una gráfica de latencia de acceso a memoria frente al tamaño del working set. Incluye dos subgráficas: una vista completa de la jerarquía de memoria (L1, L2, L3, RAM) con escala logarítmica, y un zoom lineal en L1 y L2. El código usa regiones de color (axvspan) para delimitar cada nivel de caché, líneas verticales discontinuas en los límites, y superpone una línea continua con un gráfico de escalones anotado con los valores numéricos de latencia.
