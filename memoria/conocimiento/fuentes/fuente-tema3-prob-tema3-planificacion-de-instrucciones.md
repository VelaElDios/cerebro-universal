## Resumen
Este trozo contiene 11 ejercicios resueltos del Tema 3 "Planificación de Instrucciones" de Arquitectura de Computadores. Cubre desenrollamiento de bucles y planificación estática (ejercicios 1-5), la técnica de Marcador (Scoreboard) para planificación dinámica (ejercicios 6-7), el algoritmo de Tomasulo con estaciones de reserva y CDB (ejercicios 8-10), y un caso de pipeline RISC-V con adelantamiento y salto retardado (ejercicio 11). Cada ejercicio proporciona latencias específicas, configuraciones de unidades funcionales y restricciones de hardware para practicar técnicas de ILP.
Este trozo contiene una colección de ejercicios de arquitectura de computadores (Tema 3: Planificación de instrucciones) centrados en segmentación software (software pipelining), desenrollamiento de bucles, algoritmo de Tomasulo, algoritmo de Marcador (Scoreboard), y análisis de riesgos/hazards en pipeline RISC-V con unidades funcionales de punto flotante. Incluyen enunciados completos con parámetros concretos (latencias, número de estaciones de reserva, buffers, reglas de adelantamiento y salto retardado) y piden calcular CPI, mostrar dependencias, planificar código y rellenar tablas de estad
