## Resumen
Este trozo presenta el Tema 3 "Planificación de instrucciones" del curso de Arquitectura de Computadores 2026/2027. Cubre la planificación estática (desenrollamiento de bucles, segmentación software, planificación de trazas, saltos retardados) y dinámica (Marcador, Tomasulo). Incluye bibliografía de referencia (Hennessy & Patterson, Ortega et al.), define la planificación estática como reordenación por compilador para aumentar ILP reduciendo dependencias, y detalla un ejemplo completo de desenrollamiento de bucles 4x con código RISC-V-like, latencias de unidades funcionales, forwarding y renom
Este trozo cubre dos técnicas de planificación estática de instrucciones: desenrollamiento de bucles (loop unrolling) y segmentación software (software pipelining). Se muestran ejemplos concretos en ensamblador RISC-V de suma vectorial X = X + k, comparando bucles originales, desenrollados 4 veces, y con planificación de instrucciones para eliminar detenciones. Se detallan consideraciones (sobrecarga, tamaño de código, presión de registros) y la estructura de segmentación software con código de arranque (start-up), bucle principal y finalización (finish-up), incluyendo diagramas de uso de regi
Este trozo cubre técnicas de planificación estática de instrucciones: segmentación software (software pipelining) con ejemplo en RISC-V, planificación de trazas (trace scheduling) para bucles con condicionales, comparación de técnicas estáticas (desenrollamiento, segmentación software, planificación de trazas), saltos retardados (delayed branches) y la motivación para planificación dinámica (limitación de emisión en orden).
Este trozo explica la planificación dinámica de instrucciones mediante la técnica del Marcador (Scoreboard). Describe cómo se divide la etapa ID en emisión y lectura de operandos, permitiendo ejecución fuera de orden manteniendo la corrección. Detalla los cuatro pasos del Marcador (emisión, lectura operandos, ejecución, escritura resultado), sus estructuras de datos (estado instrucciones, unidades funcionales, registros resultado) y muestra un ejemplo paso a paso con ciclos en el CDC6600.
Este trozo muestra la evolución ciclo a ciclo (ciclos 3-9) de un marcador (scoreboard) para una secuencia de instrucciones de punto flotante (cargas, multiplicación, resta, división, suma). Se detalla el estado de cada instrucción (emisión, lectura operandos, ejecución, escritura), el estado de las unidades funcionales (Entera, Mult1, Mult2, Suma, Divide) con sus campos de dependencias (Qj, Qk, Rj, Rk), y el estado de registros resultado. En el ciclo 9 la instrucción `fadd.d f6, f8, f2` aparece «Bloqueada» por riesgos WAR/WAW sobre el registro f6.
Este trozo muestra una simulación ciclo a ciclo (ciclos 10-15) del algoritmo de Tomasulo / marcador (scoreboard) para una secuencia de instrucciones de punto flotante: dos cargas (fld), una multiplicación (fmul.d), una resta (fsub.d), una división (fdiv.d) y una suma (fadd.d).
