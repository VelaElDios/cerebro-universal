## Resumen
Script Python para generar el modelo Roofline mononúcleo de una máquina. Calcula el techo de cómputo (GFLOPS máximos) a partir de la frecuencia de CPU y las capacidades AVX2/FMA (32 FLOPS/ciclo), y traza la curva min(BW_DRAM × intensidad_aritmética, GFLOPS_MAX) mostrando las regiones memory-bound y compute-bound.
