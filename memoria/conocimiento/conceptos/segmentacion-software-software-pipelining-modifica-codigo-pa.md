El software pipelining reorganiza las instrucciones de un bucle para solapar iteraciones (prologo, kernel, epilogo), reduciendo la sobrecarga de inicio/fin y aumentando el paralelismo a nivel de instrucción. Respuesta correcta: c) Menor sobrecarga.
