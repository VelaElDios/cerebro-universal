Temas: [[ac]] · [[bucles]] · [[paralelismo]]

El paralelismo a nivel de bucle (loop-level parallelism) es la posibilidad de ejecutar **diversas iteraciones de un mismo bucle de forma solapada** (pipelining de iteraciones, desenrollamiento, ejecución superscalar/Vectorial). No se refiere a sol

> El paralelismo a nivel de bucle se refiere a... a) La posibilidad de ejecutar diversas iteraciones de un mismo bucle en una máquina paralela b) La posibilidad de ejecutar diversas iteraciones de un mismo bucle de forma solapada c) La posibilidad de ejecutar de forma solapada las instrucciones de una misma iteración del bucle d) Ninguna de las anteriores
> — `repo:datos/temarios/AC/examenes/Noviembre2013.pdf`
