Temas: [[ac]] · [[dependencias]] · [[pipeline]] · [[renombrado]]

El renombrado de registros (register renaming) elimina las dependencias de nombre (name dependencies): antidependencias (WAR) y dependencias de salida (WAW). No elimina las dependencias de datos verdaderas (RAW) ni las de control.

> Renaming floating point records allows to avoid. Name dependencies.
> — `repo:datos/temarios/AC/examenes/June2023.pdf` (cita sin comprobar)
