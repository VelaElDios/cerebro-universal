Temas: [[ac]] · [[benchmarks]]

Clasificación: 1) Sintéticos (Dhrystone para entero, Whetstone para FP) — diseñados para estresar un componente. 2) Reales (compiladores, editores, CAD). 3) Núcleos (kernels): piezas clave de programas reales (Livermore Loops, Linpack). 4) Reducidos (toys): 10-100 líneas (quicksort). 5) Suites: conjuntos estandarizados por consorcios (SPEC para CPU/servidores/HPC/gráficos; TPC para transacciones/BD).

> Benchmark: carga de test o programa de prueba - programas utilizados para medir el rendimiento de un sistema informático o de alguna de sus partes
