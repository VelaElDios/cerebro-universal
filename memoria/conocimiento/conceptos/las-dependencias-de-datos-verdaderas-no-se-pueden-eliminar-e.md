Las dependencias verdaderas (RAW) son intrínsecas al flujo de datos y no se pueden eliminar. El renombrado de registros elimina solo las dependencias de nombre (WAR y WAW) que surgen por reutilización de registros arquitecturales. Respuesta correcta: b.

> Data dependences... a) Are removed by deleting branch instructions in the code b) Cannot be removed c) Are removed by register renaming d) None of the above
