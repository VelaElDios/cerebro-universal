SPEC CPU 2017 (versión 1, junio 2017) incluye 43 benchmarks y define dos métricas principales:
- SPECspeed: mide el tiempo de ejecución de una única tarea (latencia), reportado para Integer y Floating Point.
- SPECrate: mide el throughput o productividad (tareas por unidad de tiempo) bajo carga múltiple, también para Integer y Floating Point.
Ambas permiten comparar prestaciones de procesadores en cargas de trabajo reales.

> SPEC® CPU 2017 • Versión 1 (junio 2017) • Incluye 43 benchmarks  SPECspeed® – Integer / Floating Point – Comparan tiempo en ejecución de tareas  SPECrate® – Integer / Floating Point – Miden productividad por unidad de tiempo
