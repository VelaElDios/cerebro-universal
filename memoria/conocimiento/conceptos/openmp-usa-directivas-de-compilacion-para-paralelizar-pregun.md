OpenMP (Open Multi-Processing) es un API de memoria compartida que usa directivas (pragmas en C/C++, comentarios en Fortran) para indicar paralelismo al compilador. No usa paso de mensajes (MPI) ni requiere imagen de sistema unificada (SSI).
