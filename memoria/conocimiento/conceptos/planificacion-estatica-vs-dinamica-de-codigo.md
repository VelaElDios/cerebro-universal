Planificación estática: el compilador reordena instrucciones para reducir paradas (stalls) y dependencias aparentes. Planificación dinámica: hardware (Tomasulo, scoreboard) reordena en tiempo de ejecución. Opción b).

> In static code scheduling a) Hardware reorders the code to reduce dependences b) Compiler reorders the code to reduce dependences c) Hardware reorders the code to increase dependences d) None of the above
