Temas: [[ac]] · [[rendimiento]]

Si el tiempo de ejecución se reduce un 25%, el nuevo tiempo es 0,75·T_original.
Speedup = T_original / T_nuevo = 1 / 0,75 = 1,333... → 33,3% de aceleración.
La opción correcta es la a). Esta relación es inversa: speedup = 1 / (1 - reducción_fraccionaria).

> Al mejorar el hardware de un computador hemos obtenido una reducción del 25% en el tiempo de ejecución de un determinado programa de prueba a) Hemos conseguido un speedup del 33.3%
